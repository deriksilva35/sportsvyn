# Report - S3 league Pick'em format ATS (builder), 8 Oct 2026

## Recon
- Spreads: odds_markets (market_type 'spread', fetcher odds-api-v4, is_current), read home-based and
  signed by lib/gridiron/oddsReader.js getSpreadHome. No per-match spread column exists.
- Week boards: contests (game_type 'pickem', board jsonb snapshot) made by ensurePickemBoard
  (lib/pickem/create.js) at Tuesday open. A league's Pick'em is ALWAYS nfl + cfb (gameTypes.js), so
  every Pick'em league is a football league today; NBA/MLB boards are not league Pick'em.
- League scoring is read-time from contests + entries (results.js, leaderboard.js), formatAt per lock.

## Design (no migration needed: board is jsonb, 133/134 already allow 'ats')
1. FREEZE at board creation: create.js reads getSpreadHome for the slate (NFL/CFB only) and writes
   spread_home (number or null) into every contests.board[i], meta.spread_frozen_at. The snapshot is the
   only line ever graded; later moves cannot reach it. A failed read logs [ats-freeze] and stores no lines
   (the board is never failed).
2. NO LINE AT WEEK OPEN = VOID FOR ATS: neither scores nor counts in the max (nobody is graded on a
   number nobody saw). Its national result is untouched. A board created before this ships has no lines,
   so it is all void for ATS (an ATS league only starts counting at the first board made after deploy).
3. SETTLE (settle.js): perfect.ats = { results: {match_id: home|away|push|null}, max }, from the frozen
   spread and final score (home margin + spread_home > 0 home, < 0 away, = 0 PUSH). Regrade recomputes
   it inside the same 7-day window and counts a moved cover as a change.
4. PUSH = void: 0 points, not in max, shown as the P of W-L-P.
5. League score (pickFormat.js): pickemLeagueScore('ats') = picks on the covering side; a settled board
   with no perfect.ats is not a result. Record W-L-P through results.js/standings.js; recordLine prints
   W-L-P only when p is tracked (regular stays W-L).
6. Refusal: validatePickFormat / planFormatChange refuse 'ats' unless every Pick'em sport is nfl/cfb
   (code ats_sport, "Against the spread is for NFL and college football leagues only"). Also settings.js
   passes the league's real Pick'em sports.
7. UI: create sheet reads eligibleFormats() (third card "Against the spread"); league page offers every
   other eligible format (options[]); pick sheet (?league= an ATS league) shows each game's frozen line
   "AWAY +3.5 - HOME -3.5" (or "No line, so this game is void") with ATS copy and no straight-up marks.
