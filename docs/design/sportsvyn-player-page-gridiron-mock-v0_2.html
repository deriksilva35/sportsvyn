BUILD NOTES v0_2, carried into the relays:
· Hero numeral: outlined volt stroke, never filled - texture, not THE number (v1.2). No photo, no placeholder - brand law.
· Stat columns are POSITION-GROUP AWARE ACROSS BOTH CODES from one column vocabulary: QB pass, RB rush, WR/TE receiving, K kicking, LB/DB/DL defense (Tkl/TFL/Sacks/INT). Same table grammar, different columns - the fork is data, not layout.
· NFL totals = SUM over nfl_player_game_stats at read time via the bdl bridge. CFB totals = relay C's import: ONE league-wide /stats/player/season call per season, LONG-to-wide pivot at import (store wide, render dumb), ids join free per recon. CFB game logs = /games/players per completed week, rides an existing weekly cadence - no new always-on poller.
· CFB decimals are real (8.5 TFL, 0.5 sacks) - columns that can be halves render one decimal, whole-number columns never do.
· Empty state is one serif line, never a scaffolded empty table. Same line whether the cause is pre-import or genuinely zero snaps - the reader doesn't need our pipeline status.
· CFB bio strip has NO college cell (team is the college). Rookie chip = experience_years 1.
· Anchor pills render only sections that exist per player. Dormant soccer sections never render for gridiron. Soccer pages byte-identical, soccer-half pins on every test.
· HT/WT ft-in/lbs via the team-page converter, display-only.
· ALL STAT VALUES IN THIS MOCK ARE SHAPED, NOT REAL - build from real queries, never from these numbers, and none of these values may appear in fixtures.
